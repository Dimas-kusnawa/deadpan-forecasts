A program that writes one deadpan weather forecast for a city that does not exist to `/output/entry.txt` (138 characters, inside the 1–160 gate): Tomorrow in Brindlewick, expect scattered showers and a high of 18, with the showers landing exclusively on people who forgot an umbrella.

## Run it

```sh
python3 main.py
```
